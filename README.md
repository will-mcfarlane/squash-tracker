# Squash Tracker

Website: https://will-mcfarlane.github.io/squash-tracker/

## Log a match
1. Open the website and log the match.
2. Click **Save results.json** in the yellow bar and save it over `results.json` in this folder.
3. In GitHub Desktop, click **Commit to main**, then **Push origin**. The site updates in about a minute.

`index.html` is the app. `results.json` holds all players and matches.
