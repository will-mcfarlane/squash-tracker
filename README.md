# Squash Tracker

Website: https://will-mcfarlane.github.io/squash-tracker/

Log matches and add players straight on the website. Results save instantly and everyone sees them live; there are no files to save.

| File | What it is |
|---|---|
| `index.html` | The app |
| `firebase-config.js` | Connects the app to the Firebase database (project squash-tracker-c34c9) |
| `firestore.rules` | Database rules, pasted into Firebase → Firestore → Rules |

Only push from GitHub Desktop if the app itself changes.
